# AI-05 Privacy and Responsible AI Use Checklist

**CS423 / CSC15003 — Software Testing (AI-augmented, 2026)**  
Complete this checklist before submitting AI-assisted work. Check each box only after verifying the statement is true for your assignment.

## 1. Before I use AI

- [ ] I confirmed the AI Use Category assigned to this assignment.
- [ ] I declared the AI tool(s) I will use in my prompt log.
- [ ] I read the AI Use Agreement for this course.
- [ ] I understand which artifacts must not be AI-generated.

## 2. While I am using AI

- [ ] I did not enter personal data of classmates, customers, or patients.
- [ ] I did not paste copyrighted reading materials wholesale into the AI.
- [ ] I did not paste proprietary employer code or open-source code with license restrictions.
- [ ] I logged each prompt and AI response in the prompt log with its timestamp.

## 3. Before I submit my work

- [ ] All AI-generated artifacts are identified in the AI Audit Report.
- [ ] All citations suggested by AI have been verified against real sources.
- [ ] All AI-generated code has been executed and tested, if applicable.
- [ ] My 200–300-word AI Critique is included in the report.
- [ ] The Mandatory Disclosure paragraph is placed as required by the assignment.
- [ ] I attached the AI Use Disclosure Form.
- [ ] I am prepared for a 5–7-minute random oral defense during the week after submission.

## 4. Final Statement
